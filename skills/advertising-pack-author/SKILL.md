# Advertising Pack Author

Create reusable Advertising Extension Packs only when a repeated campaign grammar materially changes useful production behaviour without weakening core constraints.

## Activate when

Use when a reusable specialisation appears across projects and core defaults would otherwise carry irrelevant specialist knowledge.

Do not use for one-off campaign briefs, platform wrappers, style-only labels, provider APIs or authority overrides.

## Authoring sequence

1. inspect the current catalogue and core contract;
2. define the repeated decision problem;
3. research the production grammar and closest alternatives;
4. establish activation and explicit non-activation conditions;
5. define inputs, priorities/defaults, invariants and outputs;
6. define compatibility and precedence;
7. define bounded repair behaviour;
8. create a full showcase prompt and complete core-only comparator;
9. define positive, negative and differential criteria;
10. require actual implementation/comparison evidence before mature status.

Read [references/core-contract.md](references/core-contract.md) and [commands/author-pack.md](commands/author-pack.md).

## Return contract

Return the complete dossier, prompt pair, evaluation criteria, overlap analysis, evidence status and actual implementation/comparison results only when they genuinely exist. A design-only dossier is not an implemented or mature pack.
