# diagnose-delivery

**Owner:** `advertising-optimise`

## Purpose
Compare intended media configuration with actual activation and serving evidence.

## Inputs
Approved media/assets, actual configuration/delivery observations, change history and reporting validity.

## Outputs
Supported delivery findings, alternative causes, affected observation periods and bounded operator requests.

## Checks
Enabled is not served; no evidence is not observed zero; failed upload is not failed creative.

## Failure routing
Require actual operator return before claiming containment or repair.
