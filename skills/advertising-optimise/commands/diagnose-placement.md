# diagnose-placement

**Owner:** `advertising-optimise`

## Purpose
Determine whether context or placement is responsible for an observed advertising problem.

## Inputs
Placement role/profile, actual asset/assembly, delivery mix, observations, destination/action and change history.

## Outputs
Context-specific findings, mix-standardised comparisons where supported, alternative explanations and bounded placement/configuration request.

## Checks
Aggregate movement can be caused by mix changes. Do not label a context bad without comparable denominators and meaning.

## Failure routing
Preserve valid creative and audience decisions when only the placement/configuration layer is implicated.
