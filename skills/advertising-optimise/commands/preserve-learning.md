# preserve-learning

**Owner:** `advertising-optimise`

## Purpose
Record scoped campaign learning without converting correlation or a local outcome into universal truth.

## Inputs
Source observations, validity, context, decisions, changes, rejected alternatives and lifecycle state.

## Outputs
Attributable learning record with scope, evidence strength, validity dates/context, transferable/non-transferable implications and affected lineage.

## Checks
A measured winner in one context is not a general customer fact; an invalid test does not create a reusable lesson.

## Failure routing
Revise or retire only the unsupported learning statement while preserving source observations.
