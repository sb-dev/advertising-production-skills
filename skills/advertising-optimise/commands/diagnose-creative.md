# diagnose-creative

**Owner:** `advertising-optimise`

## Purpose
Determine whether the actual creative expression has a supported semantic/craft defect.

## Inputs
Actual output, approved message/claim/proof/master, placement and valid observations when performance is in scope.

## Outputs
Findings on opening, hierarchy, sequence, proof treatment and CTA; response hypotheses remain labelled hypotheses; return smallest repair.

## Checks
Inspect the actual requested media, not a prompt or thumbnail substitute. Invalid tracking cannot prove weak creative.

## Failure routing
Preserve sound claims and siblings; a new mechanism is a new concept, not a hidden local edit.
