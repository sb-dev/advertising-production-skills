# Advertising Optimise

Diagnose existing advertising evidence before changing work. Preserve commercial truth, valid assets and historical learning.

## Activate when

Use when actual campaign/reporting observations exist, when fatigue is suspected, when a destination or placement needs diagnosis, or when a bounded next test/repair is required.

Do not infer efficacy from absent data, rename assets to reset exposure, change offer/price/customer scope, or mutate advertising accounts without separate authority.

## Core rules

- reconcile definitions, counting units, windows, maturity and duplication before judging performance;
- separate platform attribution, verified downstream outcomes and causal evidence;
- inspect delivery, audience, creative, placement, destination, policy/claims and upstream business as distinct failure layers;
- preserve five lifecycle facets and previous observations;
- recommend the smallest supported correction or discriminating test;
- a recommendation to pause or change configuration is not the action itself.

## Return contract

Return source-separated observations, supported diagnoses versus hypotheses, exact local changes when requested, before/after preservation evidence, remaining uncertainty and the next responsible owner. Do not report a live mutation unless its actual return has been verified.
