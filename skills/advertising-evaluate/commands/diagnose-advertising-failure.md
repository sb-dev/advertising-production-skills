# diagnose-advertising-failure

**Owner:** `advertising-evaluate`

## Purpose
Triage an advertising failure to its responsible layer without rewriting everything.

## Inputs
Exact failed finding/problem, available records and validity, requested scope; performance data is not presumed.

## Outputs
Supported failures versus hypotheses across delivery, audience, creative, placement, destination, policy/claims and upstream business; missing discriminating evidence and smallest safe next action.

## Checks
Persuasiveness or vanity metrics cannot offset missing proof. Unknown cause is legitimate.

## Failure routing
Return the issue to the actual owner and preserve unaffected work/history.
