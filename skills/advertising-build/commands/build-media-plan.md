# build-media-plan

**Owner:** `advertising-build`

## Purpose
Translate an approved channel class into a campaign media plan.

## Inputs
Objective/audience, market, authorised planning budget/economics/schedule, creative/destination requirements and selected profile evidence.

## Outputs
Role-led media lines covering channel/placement role, audience hypothesis, geography, schedule, frequency/reach assumptions, optimisation objective, test allocation, exclusions, brand safety and execution requests.

## Checks
Reconcile allocations/reserve and separate forecast from observation. A daily setting is not assumed to be a hard spend ceiling.

## Failure routing
New business-wide channel choices remain upstream; absent control evidence blocks only executable plan elements.
