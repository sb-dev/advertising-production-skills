# build-creative-brief

**Owner:** `advertising-build`

## Purpose
Create a bounded specialist production request from accepted campaign meaning.

## Inputs
Accepted concept/master, exact claims/qualifications, source assets/rights, target format/fidelity and authority.

## Outputs
Exact baseline, fixed/changeable scope, modality direction, current profile, required output/provenance, cost/attempt limits and independent checks.

## Checks
Identity, source, rights and cost authority must be real. A complete brief alone is not finished media.

## Failure routing
Block only the dependent production and preserve the campaign work that remains valid.
