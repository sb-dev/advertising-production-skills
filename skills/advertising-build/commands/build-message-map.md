# build-message-map

**Owner:** `advertising-build`

## Purpose
Create the campaign message hierarchy and truthful objection responses.

## Inputs
Accepted brief/objective/audience, claim/proof state, brand, objections and intended action.

## Outputs
Primary/supporting messages, unanswered limits, CTA semantics and message/creative hypotheses with evidence links.

## Checks
Do not change the commercial exchange or invent urgency, guarantees, discounts or unsupported benefits.

## Failure routing
Return product/offer defects upstream; preserve valid messages and evidence.
