# Research Logs

This directory is the durable workspace for the `advertising-production-skills` bootstrap.

Use it to persist:

- the domain-specific bootstrap specification;
- professional advertising-practice research;
- campaign, audience, message, claim and proof models;
- creative-strategy and cross-format production decisions;
- media, targeting, placement and budget research;
- experiment, measurement, attribution and optimisation models;
- legal, standards and platform-policy context;
- AI/platform/tool comparisons;
- capability and gap matrices;
- Extension Pack research;
- progressive-example selection evidence;
- benchmark and regression architecture;
- decisions that later bootstrap stages must consume.

Conversation is an interaction surface, not the authoritative store of bootstrap research. Later stages should read the relevant research logs instead of relying on conversation history alone.

The files here are research and design records. Their presence does not mean the production repository has been scaffolded.
