# Stage 11 source register: advertising AI skills, platforms and tools

Research date: 10 September 2026. This register supports [the Stage 11 research and conformance record](2026-09-10-stage-11-ai-skills-platforms-tools-research.md). All 54 entries describe actual accessed material. A source entry is not an installed tool, an executed API, a unique independent dataset or proof that every linked document was read.

Repository bodies were read through the GitHub connector; public documentation through web retrieval. Ranges, primary search extracts, missing direct access and catalogue-only evidence are identified per source. Retrieval precision is date-only throughout; no exact timestamp is invented. A publisher time with unknown timezone stays so. Source date, current API version, package version and effective date are not interchangeable.

No private account, generated image/video/audio, actual ad-library media item, raw analytics dataset, campaign experiment, browser session, paid model call, licence agreement or PDF was analysed in this stage. No code/skill body was copied into the repository. Source findings are descriptive and bounded; candidate recommendations and requirements are original project design constrained by accepted Stages 1–10.
